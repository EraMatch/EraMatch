# GitHub Analysis Prompt Pack

This directory contains prompt templates copied from the GitHub Analysis toolkit and adapted for use inside EraMatch.

Files:
- audit.md
- categorization.md
- key_files.md
- relevance.md
- synthesis.md

Intended usage:
- Candidate GitHub profile analysis
- Technical pillar mapping against JD
- Question recommendation synthesis based on repository evidence

These prompts are now co-located under ai-service so they can be integrated by EraMatch services without external dependencies.
