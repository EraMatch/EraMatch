# EraMatch - Candidate Portal

Candidate-facing app for taking assessments, interviews, and viewing results.

## Quick Start

```bash
# Install dependencies
npm install

# Start development server (runs on port 5174)
npm run dev
```

## URLs
- **App**: http://localhost:5174
- **Backend**: http://localhost:8000 (start separately)

## Routes
| Route | Description |
|-------|-------------|
| `/login` | Candidate login |
| `/home` | Dashboard with position info |
| `/testing` | Assessment center |
| `/assessment/technical` | Technical assessment |
| `/assessment/recorded` | Recorded AI interview |
| `/assessment/live` | Live AI interview |
